**前置：离散化结果**

```
原数组：  a  = [_, 1, 5, 2, 6, 3, 5, 2]   （下标从1开始）
排序去重：b  = [1, 2, 3, 5, 6]             （m=5）
离散编号：id = [_, 1, 4, 2, 5, 3, 4, 2]
```

树1的值域是 `[1,5]`，树2的位置域是 `[1,7]`。

------

**版本0：两棵树都是空树**

```
root1[0]=0  sum[0]=0
root2[0]=0  sum[0]=0
tot=0
```

节点0是哨兵节点，`ls[0]=rs[0]=sum[0]=0`，代表空树，永远不修改它。

------

**版本1：插入 a[1]=1，id[1]=1**

树1在值域 `[1,5]` 上插入位置1，路径是：

```
[1,5] → [1,3] → [1,2] → [1,1]（叶）
新建节点：1、2、3、4
```

树2在位置域 `[1,7]` 上插入位置1（首次出现），路径是：

```
[1,7] → [1,4] → [1,2] → [1,1]（叶）
新建节点：5、6、7、8
root1[1]=1   sum[1]=1     tot变化：0→4
root2[1]=5   sum[5]=1     tot变化：4→8
prev_occ[1]=1
```

------

**版本2：插入 a[2]=5，id[2]=4**

树1插入值域位置4，路径是：

```
[1,5] → [4,5] → [4,4]（叶）
新建节点：9、10、11
```

树2插入位置2（首次出现），路径是：

```
[1,7] → [1,4] → [1,2] → [2,2]（叶）
新建节点：12、13、14、15
root1[2]=9   sum[9]=2     tot变化：8→11
root2[2]=12  sum[12]=2    tot变化：11→15
prev_occ[4]=2
```

------

**版本3到5：三种新值，各自首次出现**

| 版本 | a[i] | id[i] | 树1路径长    | 树2路径长    | 新增节点数 | tot   |
| ---- | ---- | ----- | ------------ | ------------ | ---------- | ----- |
| 3    | 2    | 2     | 4（到[2,2]） | 4（到位置3） | 4+4=8      | 15→23 |
| 4    | 6    | 5     | 3（到[5,5]） | 4（到位置4） | 3+4=7      | 23→30 |
| 5    | 3    | 3     | 3（到[3,3]） | 4（到位置5） | 3+4=7      | 30→37 |

这三步都是首次出现，树2只需一次 update，所以没有删旧操作。

```
root1[3]=16  root2[3]=20  tot=23
root1[4]=24  root2[4]=27  tot=30
root1[5]=31  root2[5]=34  tot=37
```

T2 active 从1增到5，因为每步都是新值，活跃标记数每次+1。

------

**版本6：插入 a[6]=5，id[6]=4（重复值）**

触发树2的**两次 update**。

`prev_occ[4]=2`（值5上次出现在位置2），所以：

```
step1：在旧版本上，位置2 -1  → 中间版本 tmp
       路径 [1,7]→[1,4]→[1,2]→[2,2]，新建节点：41、42、43、44

step2：在 tmp 上，位置6 +1  → root2[6]
       路径 [1,7]→[5,7]→[5,6]→[6,6]，新建节点：45、46、47、48
```

树1只做一次普通插入：

```
路径 [1,5]→[4,5]→[4,4]，新建节点：38、39、40
root1[6]=38  sum[38]=6    tot变化：37→40（+3）
root2[6]=45  sum[45]=5    tot变化：40→48（+8，两次update）
prev_occ[4]=6
```

T2 active 仍然是5，因为删了位置2的旧标记，加了位置6的新标记，总数不变。

------

**版本7：插入 a[7]=2，id[7]=2（重复值）**

`prev_occ[2]=3`（值2上次出现在位置3），同样触发两次 update：

```
step1：位置3 -1 → tmp
       路径 [1,7]→[1,4]→[3,4]→[3,3]，新建节点：53、54、55、56

step2：位置7 +1 → root2[7]
       路径 [1,7]→[5,7]→[7,7]，新建节点：57、58、59
```

树1插入值域位置2：

```
路径 [1,5]→[1,3]→[1,2]→[2,2]，新建节点：49、50、51、52
root1[7]=49  sum[49]=7    tot变化：48→52（+4）
root2[7]=57  sum[57]=5    tot变化：52→59（+7，两次update）
prev_occ[2]=7
```

T2 active 仍然是5，原因同上。

------

**tot=59 的构成**

```
树1共新建：4+3+4+3+3+3+4 = 24 个节点
树2共新建：4+4+4+4+4+8+7 = 35 个节点
                           ↑     ↑
                        一次    两次update（重复值）
合计：24+35 = 59 
```

重复值（版本6和7）各触发了两次 update。
